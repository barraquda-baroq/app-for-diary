# 作者にお願いする作業の手順書

Diary Studio（DS）を実際のスマホや PC で開いてログインできるようにするための、一度だけの作業です。
上から順に進めてください。どれも急ぎではなく、段階1（データと同期）の確かめを始める前までにできていれば十分です。

1. [手順1 Firebase のプロジェクトを作る](1-firebase-project.md)（ブラウザだけ・約5分）
2. [手順2 Google ログインと保存先（Firestore）をオンにする](2-login-and-firestore.md)（ブラウザだけ・約10分）
3. [手順3 設定値を貼り替えて公開する](3-config-and-deploy.md)（ブラウザと PC の PowerShell・約15分）
4. [手順4 ログインの戻り先を登録して、各端末で使い始める](4-login-redirect-and-devices.md)（ブラウザ・スマホ・約10分）

- プロジェクト ID は、作者が作った DS のプロジェクトの diary-studio-35f4e で書いています（公開先は https://diary-studio-35f4e.web.app）。別のプロジェクトで作り直した時は、自分のプロジェクト ID に置き換えて読んでください。
- 使う Google アカウントは、最初から最後まで同じものにしてください（NS と同じアカウントでかまいません）。
- 料金はかかりません。途中で「アップグレード」「Blaze」「お支払い」と出ても押さないでください。
