# 手順4 ログインの戻り先を登録して、各端末で使い始める

Google でログインした後に DS へ戻ってこられるよう、Google 側に戻り先を一度だけ登録します。そのあと、PC・Android・iPhone で DS を使い始めます。

- かかる時間: 約10分（登録の反映に、数分から長いと数時間かかることがあります）
- 使う物: PC のブラウザ、スマホ

## A. ログインの戻り先を登録する（最初の1回だけ）

これをしないと、ログインの時に「エラー 400: redirect_uri_mismatch」と出ます。

1. PC のブラウザで https://console.cloud.google.com/apis/credentials を開く（Firebase と同じ Google アカウントで）。

2. 画面の上のプロジェクトの選択が、DS のプロジェクト（diary-studio。ID は diary-studio-35f4e）になっていることを確かめる。
   違う時は押して選び直す。NS の novel-studio-3352e と間違えないように。
   - アドレスの後ろに ?project=diary-studio-35f4e（自分のプロジェクト ID）を付けて開くと、最初から DS のプロジェクトで開きます。
   - 画面が「Google Auth Platform」の形の時は、左のメニューの「クライアント」を開く。

3. 「OAuth 2.0 クライアント ID」の一覧の「Web client (auto created by Google Service)」を押す。
   手順2で Google ログインをオンにした時に、自動で作られています。

4. 「承認済みのリダイレクト URI」の「URI を追加」を押して、次を入れる（DS の場合。別のプロジェクトの時は diary-studio-35f4e を自分のプロジェクト ID に）。

   ```
   https://diary-studio-35f4e.web.app/__/auth/handler
   ```

   元からある「https://diary-studio-35f4e.firebaseapp.com/__/auth/handler」は消さないでください。

5. 「保存」を押す。

## B. PC でログインできるか確かめる

1. PC の Chrome か Edge で https://diary-studio-35f4e.web.app を開く。

2. 起動アニメーション → ログインの画面 →［Google でログイン］→ 小さなウインドウで Google アカウントを選ぶ → トップの画面、と進めば完了です。

3. 「エラー 400: redirect_uri_mismatch」と出た時は、A の登録がまだ反映されていない（しばらく待つ）か、URI の打ち間違いです。

## C. 各端末で使い始める

ログインは、ふだん使う形（インストールしたアプリ・ホーム画面のアイコン）で開いてからしてください。
ブラウザのタブと、インストールしたアプリ・ホーム画面のアプリとでは、端末の中の保存が別々になるためです。

### Windows の PC（Chrome か Edge）

1. ふだん使うブラウザで https://diary-studio-35f4e.web.app を開く。

2. アプリとしてインストールする。
   - Chrome: アドレスバーの右端の「インストール」アイコンを押す。見当たらない時は右上の「︙」→「キャスト、保存、共有」→「ページをアプリとしてインストール」。
   - Edge: アドレスバーの右の「アプリをインストール」を押す。見当たらない時は「…」→「アプリ」→「このサイトをアプリとしてインストール」。

3. スタートメニューの Diary Studio から開いて、［Google でログイン］。

### Android（Chrome）

1. Chrome で https://diary-studio-35f4e.web.app を開く。

2. 右上の「︙」→「ホーム画面に追加」→「インストール」（「アプリをインストール」と出ることもあります）。

3. ホーム画面（かアプリの一覧）の Diary Studio のアイコンから開いて、［Google でログイン］。

### iPhone（Chrome）

iOS 16.4 以降の Chrome なら、ホーム画面に追加して、アプリのように開けます。

1. Chrome で https://diary-studio-35f4e.web.app を開く。

2. アドレスバーの右の共有のボタン（四角から上向きの矢印）を押す。
   見当たらない時は、右下の「…」から「共有」を探す。

3. 一覧から「ホーム画面に追加」を押す（見当たらない時は、一覧を上へずらすか「その他」を押す）。
   「Web アプリとして開く」のスイッチが出た時は、オンのまま。

4. 右上の「追加」を押す。

5. ホーム画面の Diary Studio のアイコンから開いて、［Google でログイン］。
   ページが Google のログインに切り替わり、アカウントを選ぶと DS に戻ってきます。

Chrome のタブで開いた DS と、ホーム画面のアイコンから開いた DS は、端末の中のデータが別々です。
いつもホーム画面のアイコンから開いて使ってください（Chrome のタブでログインしても、ホーム画面の DS はログインしていない状態のままです）。

## 一度ログインした端末

- 次からはログインの画面を出さずに、トップの画面が開きます（電波が無くても開けます）。
- ログアウトは、歯車（設定）の［ログアウト］。端末の中のデータは消えません（同じアカウントで入り直せば続きから）。

## うまくいかない時

- 「このアドレスからはログインできません」と出た: 手順2の A の 8（承認済みドメイン）に、開いているアドレスを足す。
- 「ポップアップがブロックされました」と出た: アドレスバーの右に出るポップアップのアイコンから、このサイトのポップアップを許可する。
- iPhone でログインしたのに、次に開くとログインの画面に戻る: Chrome のタブではなく、ホーム画面のアイコンから開いてログインする。
- ほかの表示が出た時は、その画面を Claude に見せてください。
