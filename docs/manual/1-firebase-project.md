# 手順1 Firebase のプロジェクトを作る

DS のデータの置き場所とアプリの置き場所になる「Firebase のプロジェクト」を、NS とは別に新しく作ります。

- かかる時間: 約5分
- 使う物: PC のブラウザ（Chrome か Edge）
- 料金: 無料の Spark プランです。クレジットカードの登録はいりません。

## やること

1. ブラウザで https://console.firebase.google.com/ を開き、Google アカウントでログインする。
   NS と同じアカウントでかまいません。この後の手順もすべてこのアカウントで行います。

2. 「Firebase プロジェクトを作成」を押す。
   「プロジェクトを追加」「新しい Firebase プロジェクトを作成」と出ることもあります。

3. プロジェクト名に「diary-studio」と入れる。

4. 名前の下に小さく出る「プロジェクト ID」（DS の場合は diary-studio-35f4e）をメモする。
   この後の手順で何度も使います。プロジェクト ID は後から変えられません。

5. 規約の確認にチェックを入れて「続行」を押す。

6. 「Gemini in Firebase」（AI のアシスタント）を聞かれたら、オフのまま「続行」。

7. 「Google アナリティクス」はオフにして、「プロジェクトを作成」を押す。

8. 「新しいプロジェクトの準備ができました」と出たら「続行」を押す。

## できたかの確かめ

- 画面の左下か上に「Spark」と出ていれば、無料のプランです。
- NS のプロジェクト（novel-studio-3352e）とは別に、diary-studio のプロジェクトができていれば完了です。

## 気を付けること

- 「アップグレード」「Blaze」のボタンは押さないでください。カードの登録を求められるのは Blaze だけで、DS には要りません。

## 終わったら

手順2へ進んでください。メモしたプロジェクト ID は、手順3で使います。
