# 手順2 Google ログインと保存先（Firestore）をオンにする

手順1で作ったプロジェクトで、Google アカウントでのログインと、データの保存先（Firestore）と、アプリの置き場所（Hosting）を使えるようにします。

- かかる時間: 約10分
- 使う物: PC のブラウザ
- 始める前に: https://console.firebase.google.com/ で、手順1で作った diary-studio のプロジェクトを開いておく
  （NS のプロジェクトと間違えないように、画面の左上の名前を確かめてください）

## A. Google ログインをオンにする

1. 左のメニューから「Authentication」を開く。
   「構築」や「セキュリティ」のまとまりの中にあります。見当たらない時は、上の検索欄に Authentication と入れる。

2. 「始める」を押す。

3. 「ログイン方法」のタブで、一覧から「Google」を押す。

4. 「有効にする」のスイッチをオンにする。

5. 「プロジェクトの公開名」に「Diary Studio」と入れる（Google のログインの画面に出る名前です）。

6. 「プロジェクトのサポートメール」で自分のメールアドレスを選び、「保存」を押す。

7. 一覧の「Google」の行に「有効」と出ていれば OK。

8. 「設定」のタブ → 「承認済みドメイン」に、次の2つがあることを確かめる（はじめから入っています）。
   - diary-studio-xxxx.web.app
   - diary-studio-xxxx.firebaseapp.com
   （diary-studio-xxxx は自分のプロジェクト ID。無ければ「ドメインの追加」で足す）

## B. 保存先（Firestore）を作る

1. 左のメニューから「Firestore Database」を開く（見当たらない時は、検索欄に Firestore）。

2. 「データベースを作成」を押す。

3. エディションを聞かれたら「Standard エディション」を選ぶ。

4. データベース ID は「(default)」のまま。

5. ロケーションは「asia-northeast1（Tokyo）」を選んで「次へ」。
   NS と同じ場所です。後から変えられないので、ここだけ気を付けてください。

6. セキュリティ ルールは「本番環境モードで開始する」を選んで「作成」を押す。
   作った直後は誰も読み書きできない状態です。手順3で公開すると、DS の決まり（持ち主の本人だけが読み書きできる）に置き換わります。

## C. アプリの置き場所（Hosting）を始める

1. 左のメニューから「Hosting」を開く（見当たらない時は、検索欄に Hosting）。
   「App Hosting」ではなく「Hosting」を選んでください（App Hosting は有料のプランが要ります）。

2. 「始める」を押す。

3. 続けて出る説明（Firebase CLI のインストールなど）は、DS ではもう済ませてあります。コマンドは打たずに、「次へ」「次へ」「コンソールに進む」と進む。

4. Hosting の画面に「diary-studio-xxxx.web.app」が出ていれば OK です（まだ何も置いていないので、開いても DS は出ません）。

## 終わったら

手順3へ進んでください。
