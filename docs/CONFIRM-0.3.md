■ I12 Claude からの提案の見せ方と答え方（I11 の答えの読み方）

今の決め方：

- メールなどを 24時間読む常時稼働の作業で、DS に一度入れた予定などを直す・消す必要に気付いた時（例: 打ち合わせの日が変わったメール、取り消しのメール）、Claude は直さず・消さずに「提案」を出す。提案は記録を変えないので、作者が答えるまで予定などは元のまま。変わった日時を、新しい予定として足すこともしない（二重になるため）。
- 提案は「直す提案」（例: 開始日 12/3 → 12/5）と「ゴミ箱へ移す提案」の2つ。どの項目を・どう変えるか、理由（例「山田さんから、12/3 の打ち合わせを 12/5 に変えるとメールがありました」）、出どころ（どのメールか）が付く。作業の報告にも同じことを書く。
- 提案できるのは、予定・タスク・やりたいこと・ルーチン（直す・ゴミ箱へ）と、休み・ラベルの呼び名（直すだけ）。ルーチンのチェックは提案しない（その日にやったかどうかは、メールからは分からないため）。MIM は今までどおり読めず、提案もできない。
- 見せ方は「知らせない」に合わせて静かにする。通知・音・アイコンの数字・画面の下のお知らせは出さない。提案がある時だけ、ヘッダーの［MIM］の左に小さな「提案 2」の札が出る（色も動きも無い。押すと一覧）。対象の予定のカード・リストの行に小さな印が付き、予定を開くと詳細の画面の上に提案の中身が出る。設定の「Claude の操作の記録」にも残る。
- 答え方は2つ。①アプリの一覧か詳細の画面で［当てる］［当てない］を押す。②claude.ai で、直す・消すのコネクタ（…/mcp-edit）を付けた会話で「それでお願い」などと答える（24時間の作業に付けるのは読む・足す・提案するだけのコネクタ（…/mcp）なので、そのままでは作業の報告の会話に直す・消すツールが無い。作業の報告の会話にそれを付けられるか、段階6で claude.ai の作りを確かめて決める）。②の時は、Claude が直す・消すのツールを、提案と同じ変える中身（例: 開始日を 12/5 に）を入れて使うので、今までどおり claude.ai の承認の画面が出て、そこに何がどう変わるかが出る。承認すると当たる。提案と違う中身では受け付けない（中身を変えて直したい時は、変える中身を Claude に伝えて、提案とは別の直す依頼として頼む）。
- Claude が読んだ後に、その予定をアプリで直していた時（メモを書き足したなど）は、［当てる］を押すと「Claude が読んだ後に、ここで直されています」と、今の内容と提案の違いを出し、もう一度選んでもらう。
- 同じ項目に新しい提案が来たら、古い提案は取り下げて新しい方だけを出す。先に手で同じように直した・ゴミ箱へ移した時も取り下げる。30日答えなかった提案は取り下げる（予定は元のまま）。どれもお知らせは出さず、札と印が消えるだけ。
- 一度［当てない］にした提案（と、30日答えなかった提案）と同じ物は、同じメールを読み直しても、また出さない。
- 当てた提案は、Claude の操作の記録から1回の操作で元に戻せる（ゴミ箱へ移した物は、30日はゴミ箱からも戻せる）。
- アプリの設定の Claude の所に「Claude からの提案を受け取る」（初めはオン）を足す。オフにすると提案を受け付けず、札・印も出ない。

違った時に変わる所：ヘッダーの札・カードと行の印・詳細の画面・Claude の操作の記録の画面、受け取り箱の提案の形、コネクタの提案するツールと、会話で答える時の直す・消すツールの使い方（3.3・3.6・7.7・12.3・18.5・18.6・6.14・19.）

■ I13 グレーにする範囲（2026-11-10 の指摘「ログイン画面の背景はグレー、差し色もグレーが良いです」の読み方）

今の決め方：

- ログインの画面の地は、外観ごとのグレーにする（ホワイトは明るいグレー、ダーク・ディープダークは暗いグレー）。字の並べ方と［Google でログイン］のボタンは今までどおり。ボタンの枠だけはグレーの地で見えるよう --cover-border（地との差が 3:1 以上の、少し濃いグレー）にした。
- 差し色は、今まで「くすんだ青」で出していた所を全部グレーの濃淡にする: 今日の印（日付の丸・曜日の丸いラベル・今月の帯）、押した状態の［MIM］［休み］、主なボタン、選んでいる所、リンクの字、フォーカスの輪、ドラッグで落とせる所、移った先を目立たせる枠、デイリーの今の時刻の線、切り替えのオン、選んだ文字の地。色が無くても分かるよう、今日の印は輪と字の太さ、リンクは下線でも示す。
